1API가 뭔데? 구독이랑 뭐가 달라?

구독 (ChatGPT Plus 같은 거)

  • 사람이 채팅창에 직접 입력
  • 매달 정액
  • 일상 업무·검색·글쓰기용

API

  • 내 프로그램이 AI를 불러서 씀
  • 쓴 만큼 결제 (선불 충전)
  • 자동화·서비스에 AI 붙이기용
제일 많이 헷갈리는 것: ChatGPT Plus나 Claude Pro를 결제해도 API는 따로 결제해야 해요. 구독과 API는 계정도, 요금도 별개입니다.

2언제 API가 필요해?

  • 매일 반복하는 일 자동화: 아침마다 뉴스·리뷰 모아서 요약, 문의 메일 분류
  • 내 사이트·앱에 AI 붙이기: 상담 챗봇, 상품 설명 자동 생성
  • 대량 처리: 상품 500개 설명 번역, 리뷰 1,000개 감정 분석

이 사이트도 API로 돌아가요. 메인의 AI 회사 소식은 매일 자동 요약이고, 툴 모음의 AI 추천 상담도 API로 만든 거예요.

3요금 감 잡기

API는 토큰 단위로 돈을 냅니다. 토큰은 글자를 잘게 쪼갠 조각이라고 보면 돼요. 보내는 글(입력)과 받는 글(출력)의 값이 다르고, 보통 출력이 더 비쌉니다.

모델마다 가격 차이가 수십 배라서, 처음엔 싼 모델로 시작하는 게 정답이에요. (Claude는 Haiku, Gemini는 Flash, OpenAI는 mini 계열)

혼AI 추천 상담 질문 1번 (싼 모델, 툴 목록 30개 같이 보냄)약 5~9원
15분마다 판단하는 개인 자동화 봇, 하루 96번하루 몇백 원 이하
처음 연습하면서 이것저것 호출해보기$5 충전이면 한참 감

* 운영자가 직접 돌려본 실제 사용량 기준이에요. 모델과 글 길이에 따라 달라집니다.

4키 발급 (회사별)

Claude (Anthropic)
platform.claude.com
  1. 가입·로그인
  2. 결제 → 크레딧 충전
  3. API Keys → 새 키 만들기
선불 충전식. 자동 충전을 끄면 충전한 만큼만 나가요.
OpenAI
platform.openai.com
  1. 가입·로그인
  2. Settings → Billing에서 충전 (최소 $5)
  3. API keys → Create new secret key
선불 충전식. ChatGPT 구독과는 별개예요.
Gemini (Google)
aistudio.google.com
  1. 구글 계정으로 로그인
  2. Get API key → 키 만들기
무료 사용량이 있어서 연습용으로 좋아요. 단, 무료로 보낸 내용은 구글 서비스 개선에 쓰일 수 있으니 개인정보·영업 비밀은 넣지 마세요.
키는 만들 때 딱 한 번만 보여줘요. 바로 안전한 곳(아래 .env 파일)에 저장하세요.

5첫 호출 (파이썬)

파이썬이 깔려 있다는 가정이에요. 아래 순서대로 터미널에 치면 AI 답이 출력됩니다.

① 라이브러리 설치
pip install anthropic python-dotenv
② 같은 폴더에 .env 파일 만들고 키 넣기
ANTHROPIC_API_KEY=여기에_발급받은_키
③ hello.py 만들고 실행 (python hello.py)
from dotenv import load_dotenv
import anthropic

load_dotenv()  # .env에서 키를 읽어옴
client = anthropic.Anthropic()

message = client.messages.create(
    model="claude-haiku-4-5",  # 싼 모델부터. 최신 이름은 공식 문서 모델 목록 확인
    max_tokens=500,
    messages=[{"role": "user", "content": "동네 카페 인스타 소개글 3줄 써줘"}],
)
print(message.content[0].text)
① 라이브러리 설치
pip install google-genai python-dotenv
② 같은 폴더에 .env 파일 만들고 키 넣기
GEMINI_API_KEY=여기에_발급받은_키
③ hello.py 만들고 실행 (python hello.py)
from dotenv import load_dotenv
from google import genai

load_dotenv()  # .env에서 키를 읽어옴
client = genai.Client()

response = client.models.generate_content(
    model="gemini-3.5-flash",  # 무료로 쓸 수 있는 Flash 계열. 최신 이름은 AI Studio에서 확인
    contents="동네 카페 인스타 소개글 3줄 써줘",
)
print(response.text)
① 라이브러리 설치
pip install openai python-dotenv
② 같은 폴더에 .env 파일 만들고 키 넣기
OPENAI_API_KEY=여기에_발급받은_키
③ hello.py 만들고 실행 (python hello.py)
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()  # .env에서 키를 읽어옴
client = OpenAI()

response = client.responses.create(
    model="모델이름",  # 공식 문서 Models 페이지에서 mini 계열 최신 이름 확인 후 입력
    input="동네 카페 인스타 소개글 3줄 써줘",
)
print(response.output_text)

* 모델 이름은 몇 달마다 바뀌어요. 에러가 나면 대부분 모델 이름 문제니까 공식 문서의 모델 목록부터 확인하세요.

6사고 안 나는 법 (제일 중요)

  • 키를 코드에 직접 쓰지 않기. 위 예제처럼 .env 파일에 넣고, .gitignore에 .env 추가해서 깃허브에 안 올라가게.
  • 키가 유출되면 바로 폐기하고 새로 발급. 깃허브·캡처·채팅에 한 번이라도 노출됐으면 그 키는 버리세요. 공개 저장소에 올라간 키는 몇 분 만에 털립니다.
  • 자동 충전 끄고 선불로. 충전한 금액이 곧 최대 손실이라, 코드가 폭주해도 그 이상은 안 나가요.
  • 사용 한도(Spend limit) 걸기. 콘솔 결제 설정에서 월 한도를 걸 수 있어요.
  • 웹페이지(브라우저) 코드에 키 넣지 않기. 방문자가 개발자도구로 다 볼 수 있어요. 키는 서버(예: Vercel 함수)에서만.
  • 반복문엔 횟수 제한. "될 때까지 다시 호출" 같은 코드는 버그 한 번에 수천 번 호출돼요. 최대 횟수를 꼭 걸어두세요.
